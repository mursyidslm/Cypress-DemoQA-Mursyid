1. Jalankan "npm install" (untuk instal npm)
2. Jalankan "npm install papaparse" (untuk install plugin paparse agar csv bisa terbaca)
3. jalankan "npx cypress open" (untuk membuka cypress)
4. Pilih e2e Testing (untuk membuka workspace cypress e2e)
5. Pilih browser yang ingin digunakan
6. Klik button Start
